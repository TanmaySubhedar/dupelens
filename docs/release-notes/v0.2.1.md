## DupeLens 0.2.1

A small update that fixes the two things people noticed first after 0.2.0.

### What's fixed

- **Videos now show a preview.** In 0.2.0 a video only showed a grey file-type tile. Now the
  results list shows the video's first frame, and the preview pane and the full-size view play
  it, with a seek bar. Videos are read from disk in small pieces as you watch, so a large file
  does not have to load first. Some formats that Windows' built-in web view cannot play (certain
  MKV and AVI files) still show the grey tile; the files themselves are found and compared as
  before.
- **Look-alike photos are found far more often.** The default **Balanced** setting was too
  strict, so near-copies (re-saved, resized, re-compressed) were often missed. Balanced is now
  looser on all four tests, and Strict and Loose moved with it. Two different screenshots of the
  same window, with different text, are still kept apart. If you see groups you do not want, pick
  **Strict** in Settings; if you want even more, pick **Loose** (those groups are marked "Maybe"
  and nothing in them is pre-selected for deletion).

### Also in this version

- An Android test build now exists in the project (built on GitHub, not attached to this
  release). On a phone, Delete is permanent for now, because there is no trash yet.

### Install

Download the installer for your system below. Windows: the `.exe` (setup) or `.msi`. Linux:
`.deb`, `.rpm` or `.AppImage`. The app is not code-signed yet, so Windows may show a SmartScreen
warning: choose **More info**, then **Run anyway**.

Your saved scan cache and settings carry over from 0.2.0.
