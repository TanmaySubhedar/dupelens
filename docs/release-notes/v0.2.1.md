## DupeLens 0.2.1

A small update that fixes the two things people noticed first after 0.2.0.

### What's fixed

- **Videos now show a preview.** In 0.2.0 a video only showed a grey file-type tile. Now the
  results list shows the video's first frame, and the preview pane and the full-size view play
  it, with a seek bar. Videos are read from disk in small pieces as you watch, so a large file
  does not have to load first. Some formats that Windows' built-in web view cannot play (certain
  MKV and AVI files) still show the grey tile; the files themselves are found and compared as
  before.
- **Look-alike photos are found far more often.** The default **Balanced** setting was too
  strict, so near-copies (re-saved, resized, re-compressed) were often missed. Balanced is now
  looser on all four tests, and Strict and Loose moved with it. Two different screenshots of the
  same window, with different text, are still kept apart. If you see groups you do not want, pick
  **Strict** in Settings; if you want even more, pick **Loose** (those groups are marked "Maybe"
  and nothing in them is pre-selected for deletion).

### New: DupeLens for Android (early version)

The same duplicate finder, with a layout made for a phone: each group's copies in a row of large
pictures, tap to select, "Select duplicates" to tick all but the best copy, full-screen preview
(pinch to zoom, swipe between copies) and a folder browser.

- **Delete on Android is permanent for now.** There is no trash on the phone yet, so deleted
  files cannot be restored. The app asks you to confirm first. Try it on copies you can spare.
- The app needs **"Allow access to all files"**, which it asks for the first time you open it.
- For 64-bit ARM phones, which is nearly every phone made in the last decade.

### Install

Download the file for your system below.

| System | File |
|---|---|
| Windows | `DupeLens_0.2.1_x64-setup.exe` (setup) or the `.msi` |
| Linux | the `.deb`, `.rpm` or `.AppImage` |
| Android | `DupeLens_0.2.1_android-arm64.apk` |

- **Windows:** the app is not code-signed yet, so Windows may show a SmartScreen warning. Choose
  **More info**, then **Run anyway**.
- **Android:** open the downloaded file on your phone. Android will ask you to allow installing
  apps from this source (your browser or Files app); allow it for this one install. It is not
  on the Play Store.

Your saved scan cache and settings carry over from 0.2.0.
